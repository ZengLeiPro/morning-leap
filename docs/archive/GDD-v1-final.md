# 《晨光飞跃》一页纸 GDD（定稿 v1）

> 产品确认：2026-09-16 · 对齐美术规范 v1.1 · 目标约 8:00（Asia/Shanghai）前浏览器可玩 MVP

## 1. 一句话

点一下往上飞，躲过成对缝隙，飞得越远分越高；咖啡豆冲向写字楼，30 秒上手。

## 2. 平台与范围

- 单人；纯前端；单 HTML 或极简静态站（HTML + CSS + JS）
- 输入：空格 / 鼠标点击 / 触屏点击（三者等价 = 一次「飞跃」）
- 状态机：标题屏 → 游玩 → 结算 →（再来一局回游玩）
- 必须：分数、localStorage 最高分、再来一局
- 不做：账号、联网排行、商店、关卡编辑器

## 3. 核心循环

等待输入起跳 → 持续下落 / 飞跃 → 穿越缝隙得分 → 撞障碍 / 出界 → 结算 → 再来一局

## 4. 操作

| 输入 | 效果 |
|------|------|
| 空格 / 点击 / 触屏 | 给玩家一次向上冲量（飞跃） |
| 无输入 | 受重力下落 |

- 标题屏：任意飞跃键开始，或点「冲！」
- 结算屏：点「再来一局」或按空格重新开局
- 游玩中不暂停（MVP）

## 5. 实体与布局

- 画布逻辑分辨率：**400 × 600**（竖版）；CSS 等比缩放适配窗口
- 玩家：咖啡豆；绘制约 28×34 椭圆；碰撞可用同尺寸椭圆或圆 r≈14；约在屏左 1/3
- 障碍：成对写字楼 / 管道缝，上下各一块；宽 **56**；整体右 → 左移动
- 出界：顶 / 底边界算失败

详见：`/workspace/chen-guang-feiyue/art-spec-v1.1.md`

## 6. 碰撞规则

- 玩家（圆或椭圆）vs 上下障碍轴对齐矩形：相交即失败
- 穿出左边界后的障碍回收；新障碍从右侧生成
- 判定以碰撞为准，不做像素级贴图判定
- 缝内视觉安全边距 ≥8px（碰撞与绘制同框，勿再内缩）

## 7. 计分

- 每成功穿过 1 对障碍缝隙：+1 分
- HUD 实时显示当前分；结算显示本局分 + 历史最高分
- 最高分 localStorage key：**`morning-leap-best`**（统一，勿用旧 key）
- 刷新最高分时，结算文案走「新纪录」

## 8. 难度曲线（前 10 秒宽松）

时间轴（开局 t=0）：

- **0–3s**：热身；第一对障碍约 t≈2.5–3.5s 进入
- **3–10s**：缝隙偏大、水平间距偏宽、移速偏低
- **10–25s**：收到标准难度；移速温和上升
- **25s+**：移速缓慢继续升，缝隙略收，设软上限避免不可玩

参数基准（对齐美术，客户端可微调）：

| 参数 | 热身 | 标准 | 后期软限 |
|------|------|------|----------|
| 缝隙高 gapH | ~170–180 | **150** | 不低于 ~120–130 |
| 障碍宽 | 56 | 56 | 56 |
| 水平间距 | 偏宽 | 标准 | 略收 |
| 移速 | 慢 | 中 | 封顶 |

手感目标：点 1–2 次可稳住过缝。

## 9. 胜负

- 无通关；失败：碰撞障碍或出上下界
- 「胜利感」来自破纪录与连续穿越

## 10. 文案

- 标题：《晨光飞跃》
- 副标题 / 提示：点一下 · 冲楼缝（或：点击 / 空格 飞跃）
- 开始按钮：冲！
- 失败文案（结算随机 1 条）：
  - 「迟到了…但香气还在。」
  - 「撞上玻璃幕墙，HR 已读不回。」
  - 「这栋楼的缝，比电梯还难等。」
  - 「豆碎了，梦想还在飘。」
  - 「建议下次走楼梯。」
- 新纪录：破纪录！多喝一口再战
- 未破纪录：再飞一程？
- 再来一局按钮：再来一局
- 分数标签：本局 / 最高

## 11. 音频

- P0：可静音无音效先上线
- P1：飞跃短音、得分嘀、撞墙闷响（无版权或程序哔哔）

## 12. 验收标准（给测试）

- 桌面：空格 + 鼠标可完整开局 → 得分 → 失败 → 再来
- 手机：触屏可玩；无横向强制滚动；按钮可点
- 刷新后最高分仍在（key：`morning-leap-best`）
- 前约 10 秒明显比后期宽松
- 无白屏 / 卡死；快速连点不崩
