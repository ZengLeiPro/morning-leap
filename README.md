# 晨光飞跃（Morning Leap）

浏览器可玩的一键躲避小游戏：咖啡豆冲向写字楼缝隙。

## 怎么玩

- 本地：用浏览器直接打开 `index.html`，或在本目录执行 `python3 -m http.server 8080` 后访问 http://localhost:8080
- 操作：空格 / 鼠标点击 / 触屏 = 飞跃
- 目标：穿过楼缝得分，撞障或出界结束；刷新后保留最高分

## MVP 范围

- 画布 400×600，纯前端 Canvas，无构建
- localStorage key：`morning-leap-best`
- 对齐 GDD 定稿与美术规范 v1.1
