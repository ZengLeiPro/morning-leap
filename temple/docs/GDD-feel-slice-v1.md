## 3. 画面与缩放

- 逻辑画布：**320×180**，瓦片 **16×16**
- `imageSmoothingEnabled = false`；CSS/canvas **nearest 整数倍**铺满（2×/3×/4×…），禁止模糊插值
- 高分屏必须锐利；糊 = P0 不过

## 5. 操作（P0，推倒重做）

| 行为 | 规则 |
|------|------|
| 移动 | 按住连续；斜向速度归一；松键即停，无滑步黏滞 |
| 挥剑 | 独立键（J/Z）；与对话键分离；短前摇；有效帧对齐 Puny sword 列 7–8 |
| 对话 | E/Enter；攻击键在对话中**不**挥剑 |
| 触控 | 左摇杆死区；右「剑」；点 NPC/对话框确认；无误触满屏砍 |

目标：陌生人 **30 秒内**觉得顺手。

手感初值（可调）：移速约逻辑 **60–70 px/s**；挥剑总长约 180–220ms；受伤无敌 **600–800ms**；命中 **hitstop 2–3 帧**。

## 9. 验收闸（愿再玩）

**P0**

1. 高分屏 nearest 锐利，无模糊插值；中文 UI（标题/HUD/对话框）清晰可读（可用 DOM 叠层）  
1b. 地图底边留 ≥1 瓦，不被视口裁切  
2. 公开图块/角色表成品，非矢量糊脸  
3. 移动/挥剑/对话/触控 30 秒顺手（键分离、无黏滞）  
4. 先见锁 → 开关开北门 → Boss 可打（结构完整）  

**P1**：命中汁、Boss 两招可辨、HUD 不糊  

**回归**：村→三房→Boss 能走通；**不通关不单独否决「愿再玩」**

结论：可交付 / 带病交付 / 不可交付 —— 以「愿再玩」为主，不以通关速度为主。
